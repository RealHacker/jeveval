What leaves your browser

During a run, the task, current viewport screenshot, page URL/title, action history, and collected results are sent to TypeSafe. Screenshots can contain private information visible on the page. Your API key is sent only to api.typesafe.ai.

Request history is saved in extension localStorage on this device. Screenshots are kept in memory only. No analytics or other backend is used. The API key is stored locally, without application-level encryption.

JevBot can read and act on HTTP(S) pages. It requests broad site access so automation can continue across navigation. Only start tasks on pages you want it to operate on.
